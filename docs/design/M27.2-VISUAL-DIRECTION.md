# Atlas M27.2 — Visual Direction & Architecture Review

Status: **PROPOSAL — no implementation**. Read-only audit of the M27.1 tree;
nothing outside this document is touched by M27.2.

## 0. Verdict on M27.1 (why redesign, not patch)

M27.1 is a correct data architecture wearing a placeholder layout. Its
structural choices cannot evolve into a control room by styling alone:

- **Top-bar + centered column** (`Shell` variant + `max-w-6xl`) is a document
  layout. A control room needs a persistent sidebar, a full-bleed viewport,
  and a pinned inspector — three regions the current `Shell` cannot express
  without breaking every route.
- **Lens tabs switch the panel, the Island stays mounted** — right idea, but
  the viewport is a small canvas inside a scrolling column, not the primary
  surface. Patching sizes will not fix the hierarchy.
- **Every building and worker gets a permanent 3D label** (`client.ts`
  `labelOf` per entity). Overlap is structural, not tunable. The label
  system must be redesigned (LOD + anomaly-only default), not restyled.
- **Buildings are status-agnostic gray boxes with a status lamp.**
  The Island therefore reads as architecture, not execution. Status must
  move into mass/color/light, which is a projector change, not CSS.
- **Progress is fabricated-adjacent**: `doneCount = verified + merges`
  double-counts integrated tasks (a merged task was verified first) and the
  bar implies a completeness the engine never asserts. It must be replaced
  by honest stage counts.
- **No sidebar, no timeline, no inspector hierarchy, no stat strip.**
  These are the reference's load-bearing structures; none exist.

What M27.1 got right and is preserved untouched: the
`WorkflowGraphData → IslandScene → projector` split, the poll/diff/play
loop, the read-only Zod API contracts, ortho camera, reduced-motion
posture, selection plumbing (`onPick`/`select`), and the SSR dashboard.

## 1. Design principles (control room, not dashboard)

1. **The Island is the workspace.** Full-bleed viewport, always mounted in
   the run workspace, never a card inside a column.
2. **Sidebar owns navigation; viewport owns state; inspector owns detail.**
   Three fixed regions, zero competing hierarchies.
3. **Every pixel traces to persisted rows.** Statuses, counts, timestamps,
   verdicts, SHAs — all from SQLite via loaders. Derived values (elapsed
   time, sequence numbers) are labeled as derived and computed from real
   timestamps, never synthesized.
4. **Status is light and mass, not decoration.** Blue = actionable/live
   only. Green/amber/red carry status and appear nowhere else.
5. **Motion is state change.** Keep the diff-player model: transitions play
   only when polled state actually changed. No ambient animation.
6. **Density is a first-class requirement.** The design must be specified
   at 1, 20, 100, and 200+ tasks (§7), not just the 3-task reference run.
7. **Keyboard and list parity.** The 3D canvas is never the only path to
   any entity or action.

## 2. Reference interpretation (take / reject)

The supplied reference (sidebar + viewport + inspector + timeline + stat
strip, graphite, electric-blue accents) is adopted as **layout grammar**,
not as styling to copy and not as data to trust. Concretely:

TAKE: sidebar nav with projects; run header (back / title / status pill /
meta line / updated-freshness / share-menu); lens tabs; viewport view
controls (Perspective|Top, Reset, fullscreen); floating status chips on the
Island; legend overlay; right inspector with tabs and close; bottom stat
strip; bottom workflow timeline with ordered node cards; workers panel.
REJECT / DOWNGRADE (all verified against `prisma/schema.prisma` and
`src/ui/data.ts` — none of these exist as stored or loaded facts):
- Task **"Type: CODE"** — Task has no type column. No type chip; claims
  (`resourceClaims` paths) are the honest type signal.
- Worker **40% progress bar** — no progress column exists. Banned outright.
  Worker rows show status + assignment + test counts only.
- **Logs tab** — no log store exists. Inspector tabs are
  Overview / Dependencies / Evidence (artifacts + test runs + commits).
  No Logs tab until a log store exists.
- **"waiting" state** — not an engine status. Use real statuses
  (READY / PENDING / BLOCKED) with honest labels.
- Task **"Started 2 minutes ago"** — derivable from the earliest
  task-scoped scheduling event (`TASK_SCHEDULED`/`TASK_ASSIGNED`), so it
  may be shown labeled as derived; never stored or guessed.
- **Elapsed 3m 12s** — derivable from `Feature.createdAt`; allowed once
  the timestamp is added to the workspace payload (read-only addition).
- **Outputs / Artifacts content** — `Artifact` rows (type/label/location)
  and `Commit` rows (sha/subject) are real and currently unexposed; wiring
  them into an Evidence tab is in scope as a read-only loader extension.
- **"1. migrate schema" numbering** — allowed only as wave/level sequence
  position, labeled as such, never as priority.

## 4. Screen specifications

### 4.1 Home — fleet attention, not vanity metrics
Keep M27.1's live strip + Needs-attention + run rows. Changes:
- Replace `verifiedCount + mergeCount` progress with **stage segments**:
  `done (COMPLETED*) / active (CLAIMED|IN_PROGRESS|VERIFICATION) /
  failed (FAILED|CANCELLED|BLOCKED?) / idle (rest)`, all from
  `RunSummary` task counts. Segmented bar, no single %.
- Needs-attention admits runs with failed tasks, halted trains
  (`INTEGRATION_FAILED` latest), or **pending approvals**
  (`Approval` PENDING rows — real, currently unused).
- Drop the six generic metric cards entirely.

### 4.2 Runs — keep the M27.1 table, add stage segments + halt flag
The filterable status table stays; progress column becomes the stage
segment bar; rows for halted runs carry a halt chip. No redesign needed
beyond the progress honesty fix.

### 4.3 Run workspace (primary surface)
Regions, in order: run header → lens tabs → viewport + inspector (row) →
stat strip → timeline + workers row. Viewport is `flex-1`, min 60vh,
border-framed (not full-window-bleed: the reference keeps a framed map —
adopt that; true edge-to-edge bleed fights the sidebar + inspector).
