## 3. Experimental protocol (pre-registered)
- Primary outcome: verified success rate per arm/class.
- Secondary: wall medians, usage completeness.
- Success predicate (shared): completed + verified + non-empty +
  integrated (`runner.ts`).
- Failure classes: code / rate-limit / unavailable / context /
  infrastructure / timeout / integration / verification / inconclusive.
  Provider failures never counted as code failures.
- Exclusion rules: invalid-harness runs only, documented with rerun
  artifacts versioned separately.
- Expansion: real cells split 3–4/5 AND cheapest → n=10; else hold n=5.
- Per-trial timeout 10 min; agent calls capped at 240s each.

## 4. Workload and fixture descriptions
1. **Independent** (`realistic-independent`): login + billing, disjoint
   files, no deps. Parallel-valid. Risk: none structural.
2. **Sequential** (`realistic-schema-api`): schema → validator chain.
   Parallelism structurally useless within chain.
3. **Shared-interface** (`realistic-false-parallelism`): two WRITE
   claims on one settings file, disjoint lines. Tests serialization +
   clean merge.
4. **Integration-heavy** (`realistic-mixed`): b/c collide on one file;
   halt-with-conflict expected — informative, not a failure of method.
5. **Migration** (`realistic-migration`, new M28.9): schema → pure
   migrate fn → reader; 3 test files incl. idempotence. Elevated
   verification per task.

## 8. Usage and cost completeness
0% across all real trials: the pilot invokes opencode in default
format, which emits no usage envelope (proven: rerun artifacts show
`usage.tokens: null` on 30/30). A separate probe proves `--format
json` yields real `step_finish` token counts. Cost: free tier reports
`0` where observed; paid tiers unmeasured. Conclusion: metering is one
invocation flag away, but that flag changes provider output format —
adopting it requires a control comparison before it can be trusted not
to perturb agent behavior.

## 10. Class-level evidence statuses
1. **Independent: single-agent sufficient for tested conditions.**
   Both arms 5/5; +7s Atlas overhead on ~30s tasks. No evidence that
   orchestration helps here.
2. **Sequential: single-agent sufficient for tested conditions**
   (with a note). A 5/5 vs B 4/5; the one B failure is an agent empty
   contribution, not orchestration. +18s overhead tracks the extra
   sequential agent call, not scheduler pathology.
3. **Shared-interface: further evaluation justified.** A 5/5 vs B 0/5
   (all merge conflicts after fully verified work). The train behaved
   correctly; the question is whether the conflict rate is fixture
   artifact (whole-file rewrites) or structural. Needs a fixture where
   agents edit disjoint lines in place.
4. **Integration-heavy: further evaluation justified.** Designed
   collision produced exactly the designed halt (2 INTEGRATED + 1
   CONFLICT, 5/5 identical). The mechanism is proven; its frequency on
   realistic coupling is unmeasured.
5. **Migration: further evaluation justified.** A/B both 5/5 but B
   costs ~3× wall (107s vs 38s) on a 3-task chain — the steepest
   overhead ratio observed. Worth decomposing before judging.

## 11. Threats to validity
n=5 screening; synthetic fixtures; one free model; machine-shared
timing noise; stub arm never mixed with quality conclusions; rerun
replaces quarantined data by documented design (not silent);
free-tier quota unknown (75 sequential calls consumed none
observable); real-browser drag behavior irrelevant here (CLI-only
experiment).

## 12. Explicit decisions and unresolved questions
- Optimization: NO-GO reaffirmed (no scheduler/git pathology; overhead
  tracks agent calls + integration, both by design).
- n=10 expansion: NOT justified — no cell split 3–4/5 on valid data
  (schemaApi B 4/5 and mixed A 4/5 are single genuine agent-behavior
  outcomes, not threshold cases; expanding would chase noise).
- Metering: adopt `--format json` invocation ONLY after a control
  comparison proves it doesn't perturb agent behavior.
- Unresolved: shared-file conflict rate (fixture vs structural),
  migration overhead decomposition, paid-tier behavior, contention
  beyond sequential execution.

fixture to separate fixture artifact from structural conflict risk;
(2) `--format json` control comparison (same tasks, both formats);

No scheduler, caching, provider, or merge changes.
