## 2. Design and framework decisions
- **Standalone Vite app** `apps/docs-site/` (`@atlas/docs-site`, port
  5175), registered in `pnpm-workspace.yaml`. Rationale: `apps/web` is
  a live product surface with 30+ in-flight files; repurposing it would
  collide with active work. The docs app shares only the Atlas graphite
  token *intent* and lucide-react, with its own editorial layer
  (Inter/JetBrains Mono via system stacks, violet research accent).
- **No new dependencies beyond the workspace's existing set**: react,
  react-dom, lucide-react, vite, tailwindcss, typescript, vitest,
  @playwright/test — all already in the pnpm store.
- **Hash routing** (`#/docs/...`, `#/research/...`, `#/timeline`):
  static-preview friendly, no server fallback needed, consistent with
  the existing `apps/web` convention.
- **Local search**: hand-built index over pages, experiments, commands,
  and concepts — no external service. Keyboard (`/`), arrow-key
  navigation, Escape, click-outside.
- **No syntax-highlighting library**: minimal tokenizer for sh/json
  (comments, flags, strings, numbers) to avoid a new dependency.
