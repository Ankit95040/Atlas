## 4. Arm definitions and fairness limitations
- **Arm A (single agent)**: one real agent, whole-task prompt
  (`renderSingleAgentPrompt`: union of sections), union claims, one
  worktree, same test command. Limitation: union context inherently
  larger than any decomposed slice — that IS the treatment being
  tested, not a confound, but it must be stated.
- **Arm B (Atlas)**: unmodified plan/claims/waves/verify/train via
  `runOneRealStrategy`. Limitation: decomposition is human-authored
  (M14 control), so this measures orchestration, not planning quality.
- **Arm C (stub)**: `script-agent.mjs` behaviors; measures overhead only.
- Fairness blockers: no authorized model/budget (Arm A/B unexecuted);
  token telemetry structurally null through `CommandWorkerProvider`
  (M8/M11 boundary drops stdout) — cost-per-success requires either
  provider-side reporting or external metering, both unresolved.

## 5. Metrics and data schema
Quality: verified completion, partial, regression, integration-failure
rates + final verdict — all derivable from `RealRunResult`
(success/workerMs/verification/testStatus/integration.status).
Time: wall-clock + `schedulingMs/workerMs/assignMs/verificationMs/
trainMs/testMs` (M28.2). Cost: calls counted; tokens/cost **missing by
design** → represented null, never zero. Operational: retries (always
zero by policy), repairs (rework field), interventions (manual — none
in harness), failure category (RAW+VALID taxonomy), missing telemetry
(`missing[]` convention + nullable schema fields).

## 6. Experimental controls
Same task statement (shared renderer) + acceptance criteria (same
`testCommand` + success predicate) + starting snapshot (fresh fixture,
pinned base commit, pristine assertions before/after) + provider/model
+ tools/permissions (same argv/env allowlist) + timeout (level
constant) + suite + success def, across arms. Randomize arm order per
repeat; pair trials by (workload, repeat) sharing one fixture repo
snapshot. Unavoidable difference: Arm A union context vs Arm B sliced
context (the treatment itself — declared, not hidden).

## 7. Reproducibility procedure (M28.6 pilot)
1. Pin model + version + temperature in `RealAgentConfig`; record.
2. Select workloads (recommend INDEPENDENT + CHAIN first: smallest
  Licensed-context confound).
3. `repeats: 5` (screening; label as such), randomized arm order,
   fresh fixture + scratch per trial (existing discipline).
4. Aggregate with `compareRealRuns` (populations never mixed);
   report per §7 of the milestone (n, rate, median, p90, spread,
   cost-per-success or explicit missing).
5. Publish raw `RealRunResult` JSON + the comparison object as the
   artifact. Budget gate: authorize max spend + per-trial timeout
   before the first trial.
